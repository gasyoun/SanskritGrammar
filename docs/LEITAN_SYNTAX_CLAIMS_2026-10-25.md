# Claims-план по конспекту Лейтана: 25 утверждений (приложение B)

**Зачем:** решение гриля 25-10-2026 (№ 10) — собрать 20–30 проверяемых утверждений
из конспекта и из моста по превербам, каждое с инструментом проверки. Это план,
не harvest: статус у всех `pending`, ни одно утверждение не промотировано в
`claims.yml`.

**Легенда.** Источник: `конспект` — утверждение явно есть в тексте; `Шпеер`/`Апте` —
норма, на которую опирается мост (приложение A) и которую надо проверить до
преподавания. Проверка: `treebank` — DCS treebank (образец:
[`ZalizniakOcherk_1978/treebank_syntax_stats.py`](https://github.com/gasyoun/SanskritGrammar/blob/main/ZalizniakOcherk_1978/treebank_syntax_stats.py));
`DCS` — частотный запрос по DCS SQLite; `reference-Whitney` — сверка с
[`WhitneyGrammar_1889`](https://github.com/gasyoun/SanskritGrammar/tree/main/WhitneyGrammar_1889);
`text` — внутренняя проверка по корпусу конспекта.

**Дубли.** Перед промоушеном сверить с `APT-1..39` и `SPE-H-1..40`: часть утверждений
о пассиве, абсолютном локативе и коррелятивах там уже есть.
