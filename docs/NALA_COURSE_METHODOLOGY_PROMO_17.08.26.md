## Курс одним абзацем

Живой, непрерывный, преподавательский курс чтения «Сказания о Нале» — истории Наля и
Дамаянти, с которой в Индии веками начинали чтение Махабхараты: язык яснее эпического
среднего, сюжет держит внимание, стих — классическая шлока. Курс продаётся и ведётся как
любой курс Systema (Course + Tariff + CourseBlock + Group + Schedule), но, в отличие от
конечных курсов, **не имеет финиша**: группа прошла 65+ живых занятий ещё до появления
курсовой инфраструктуры (главы 1–10 третьей книги, по метаданным
[архива стенограмм](https://github.com/gasyoun/Uprava/blob/main/stenogrammy/MANIFEST.jsonl))
и продолжает. Решения зафиксированы в
[PLAN_NALOPAKHYANA_SUBHASHITA_COURSES_2026.md](https://github.com/gasyoun/Uprava/blob/main/docs/PLAN_NALOPAKHYANA_SUBHASHITA_COURSES_2026.md)
(D1–D12).

## Методика преподавания (что фиксируют источники)

1. **Единица курса — блок из 4 занятий** (D6): у Systema нет «недель» и «потоков», продаётся
   блоками; для Нали `CourseBlock.ends_at` остаётся открытым — курс без конечной даты.
2. **Структура занятия** (зафиксирована в
   [лендинге курса](https://github.com/gasyoun/ORS-FAQ/blob/main/docs/landing_nalopakhyana.md), H2171):
   чтение вслух (деванагари, шлока) → пословный разбор (форма, основа, значение) →
   перевод фрагмента → разговор о сюжете, культуре, поэтике. Грамматика подаётся на
   настоящем тексте, не на упражнениях.
3. **Живой формат**: Zoom, преподаватель, записи всех занятий, закрытый чат группы с
   материалами (D9). Вход — «с ближайшего занятия», без ожидания потока.
4. **Кабинетное дополнение — пакеты kosha** `nala-1/2/3` (MBh 3.50–3.52, D3): готовый
   reading-pack контур, ноль новой лингвистики; выдача блоков — по решению исполнителя
   контентной волны (последовательно или сразу).
5. **Учительская рамка курса** — единственная разрешённая цитата первого лица из
   вступления преподавателя: «Я хочу верить, что то, что сегодня начнется, продолжится
   несколько лет...» — открытость горизонта заявлена с первого занятия и совпадает с
   продуктовой формой (курс без финиша).

## Промо-основа (что честно продаёт курс)

- **Трек-рекорд вместо обещаний**: 65+ живых занятий уже проведено — «присоединяйтесь к
  идущему чтению», а не «запишитесь на будущий поток».
- **Анти-марафон**: никакого «санскрита за месяц»; привычка читать регулярно — то, чего
  не даёт интенсив (формулировки лендинга H2171).
- **Пословная честность**: «понятно каждое слово, а не "примерно о чём"» — главный
  методический дифференциатор.
- **Классический вход в Махабхарату**: культурная легитимация («с этой истории веками
  начинали») — уже отработана в лендинге.
- Пара к конечному курсу [Subhāṣita 4×4](https://github.com/gasyoun/SanskritGrammar/blob/main/docs/CURRICULUM_SUBHASHITA_4X4.md)
  (D5: независимые параллельные предложения; контраст «конечный 16-урочный» vs
  «непрерывный без финиша» — см.
  [карту курсов](https://github.com/gasyoun/SanskritGrammar/blob/main/docs/CURRICULUM_START_CHTENIYA_W1_W5.md), H2172).
- **Биллинг** (D10): сейчас — обычная разовая оплата; месячная подписка (H2026 Mode A)
  включится автоматически после разблокировки Точки
  ([Systema-Sanscriticum#998](https://github.com/gasyoun/Systema-Sanscriticum/issues/998)).
  Цифры цен и даты в промо-материалах не живут (D7) — только samskrte.ru.

## Ограничения — недоступно по построению (no-transcript ruling 17-08-2026)

Только стенограмма могла бы подтвердить — здесь этого нет и **не аппроксимировано**:

- фактический темп «стихов/глав за занятие» по сессиям;
- повторяющиеся преподавательские приёмы и хуки сверх единственной разрешённой цитаты;
- паттерны работы с вопросами студентов (152-ФЗ-контент по определению).

Путь дообогащения: человек сам извлекает из стенограммы обезличенную выжимку и передаёт
её как НОВЫЙ источник — тогда минтуется отдельный handoff; автоматический разбор тел
запрещён бессрочно.
