# Управление глаголов в ключах Кочергиной — линт по НКРЯ (H5400)

_Created: 25-09-2026 · Last updated: 25-09-2026_

Шаг 4 родительского [H5285](https://github.com/gasyoun/Uprava/blob/main/handoffs/archive/H5285-Opus_Systema-Sanscriticum_nkrya-beginner-gloss-lint_23.09.26.md):
тот линт проверял однословные глоссы, этот — **синтаксис ключей**: падеж и предлог при
глаголе в русских ответах к учебнику. Вопрос один: не учит ли ключ управлению, которое
в современном русском редко или встречается только в текстах XIX века.

Инструмент: [`verb_government_lint.py`](https://github.com/gasyoun/SanskritGrammar/blob/main/KocherginaUchebnik_1998/verb_government_lint.py).
Формулировки учителя не переписываются (грилл 23-09-2026, Q3): линт только помечает,
подсказка попадает в ключ лишь после голосования.

## Блокер: на этой машине нет токена НКРЯ

`csl_pyutil.nkrya.load_token()` возвращает пусто: нет ни переменной `NKRYA_TOKEN`, ни
записи в хранилище ключей (проверено 25-09-2026 на Windows-боксе Claude/c1; в
`~/.secrets/` записи НКРЯ тоже нет). Поэтому **все 38 пригодных пар стоят как `unknown`,
а не как «флагов нет»** — отсутствие данных никогда не выдаётся за чистый результат.
Кэш сырых ответов (957 файлов в `SanskritLexicography/RussianTranslation/pwg_ru/nkrya_cache`)
запросов по управлению не содержит: он собран под частотные и парные запросы H5261/H5262.

Живой прогон — на боксе с токеном (mac, ключ в keychain) одной командой:

```
python KocherginaUchebnik_1998/verb_government_lint.py --sheet
```

Цена прогона: 31 запрос `sketch` (по одному на глагол) + 17 × 2 запроса конкорданса
(современный срез 1950+ и срез XIX в.) = **65 запросов ≈ 65 минут** при измеренном
лимите ~60 успешных вызовов в час на аккаунт. Прогон возобновляем: кэш
[`verb_government_evidence.tsv`](https://github.com/gasyoun/SanskritGrammar/blob/main/KocherginaUchebnik_1998/verb_government_evidence.tsv)
сохраняется каждые 20 вызовов, `--max-lookups N` режет прогон на куски, `--offline`
пересобирает TSV из кэша без сети.

## Как считается флаг

1. **Тир A — `sketch(глагол, "V")`.** Словесный портрет НКРЯ отдаёт синтаксические
   отношения глагола: это и есть профиль управления. Один вызов на глагол; форма
   запроса уже обкатана в продакшене (H5261).
2. **Тир B — конкорданс `lex + dist`.** «Глагол … предлог» в пределах 1–3 слов,
   посчитанный дважды: подкорпус 1950+ и подкорпус 1800–1899. Форма запроса — та же,
   что в H5285 (`pair_query`), проверена на живых ответах.
   - 1950+ = 0 и XIX в. > 0 → `c19_only` (главный улов: управление, вымершее в XX в.);
   - 1950+ = 0 и XIX в. = 0 → `zero_modern` (скорее ошибка извлечения, чем архаизм);
   - 1950+ ниже `--rare-hits` (по умолчанию 20) → `rare`.
3. **Беспредложное управление** (глагол + чистый падеж) помечается
   `case_only_review`: поле `gramm` в lex-gramm API нашей кодовой базой ещё не
   проверялось живым ответом, и вместо непроверенной формы запроса линт отдаёт
   отношения из тира A человеку. Достроить тир C — отдельная работа, когда появится
   токен и можно будет проверить форму запроса одним вызовом.

Флагированные пары (не более 10) уходят спецификацией review-листа в
`review/specs/sanskritgrammar-kochergina-verb-government.json` (ключ `--sheet`);
карточка спрашивает только «оставить как есть / добавить подсказку / отложить».

## Очередь на живой прогон

Предложные пары (тир B, по ним флаг считается механически):

| глагол | предлог + падеж | локус |
|---|---|---|
| видеть | в + П. | X-2, XII-2 |
| возлежать | на + П. | XXXII-1 |
| жаждать | с + Т. | XXXIX-2 |
| отпустить | перед + Т. | XXXVII-2 |
| падать | на + В. | X-1 |
| потерять | из-за + Р. | XXI-1 |
| привязывать | к + Д. | XVI-2 |
| проверять | по + Д. | XXX-1 |
| произойти | в + П. | XXXIX-1 |
| согласоваться | с + Т. | XXXII-1 |
| спрятать | в + П. | zan1/nol/yoga-07 |
| уйти | в + В. | XXXVII-2 |

Беспредложные пары (тир A / будущий тир C) — 24 штуки, среди них те, где архаизм
правдоподобен заранее и человеку стоит смотреть первыми: **жить + Т.** («жертвенным
возлиянием живут боги»), **жаждать + Р.** («жаждут встречи»), **обуздывать + В.**,
**сдержать + В.** («сдержать слово»), **сыпать + В. + Д.** («сыплющих зерно птицам»),
**соответствовать + Д.** Заранее ничего из этого флагом не помечено: догадка — не
проверка.

## Что инструмент НЕ делает

- не правит ключи и не предлагает замену формулировки;
- не лезет в упражнения (только ответы) и не трогает санскритскую часть;
- не выдаёт «флагов нет» без данных: пустой кэш = `unknown`;
- не строит беспредложный запрос по непроверенной форме поля `gramm`.
