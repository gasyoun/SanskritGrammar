**Ruling applied (MG 07-09 + 09-09-2026):** большинство томов УЖЕ ИЗДАНО — census classifies per tom with evidence, NEVER assumes unfinished. Серия = «Bibliotheca Sanscritica» МГ; Фриш — автор только 2 томов (I–II). Путь = (б) электронное издание (docx→mdx). Pilot tom = Лихушина (`33_Lihusina`).

## Method

Per-tom recursive `rclone lsf` over `yadisk:Bibliotheca/NN том …` (listings taken 10-09-2026), classification by file evidence:

- **ИЗДАН** — печатные финалы присутствуют: `В печать/` with final block PDF/cover, or ozon/promo specimen, or ebook export.
- **В ПРАВКЕ** — верстка финал существует, но печать не видна (письмо/рассмотрение/внешнее издательство).
- **НЕ НАЧАТ** — нет ни одного `.indd`/`.idml` версточного файла (только исходники/сканы/OCR).

Верстки считаются по наличию `.indd`/`.idml`; даты — mtime на yadisk. Воспроизведение: `rclone lsf -R --format pst --separator "|" "yadisk:Bibliotheca/NN том X"` для каждого тома.

## Limitations

- Attribution «предв.» = вывод из имён файлов, не из титулов; D-решения не зависят от атрибуции.
- mtime yadisk ≠ дата издания; состояния классифицированы консервативно (печать = только при прямых print-артефактах).
- Внутритомовые вспомогательные папки (Links/, Document fonts/) учитывались только как шум; содержание не читалось (derived-only, файлы не коммитятся).
