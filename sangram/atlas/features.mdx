# Каталог возможностей

_Создано: 25-08-2026 · Последнее обновление: 25-08-2026_

Шестое представление [атласа](https://gasyoun.github.io/SanskritGrammar/grammars/sangram/atlas).
Оно отвечает на один вопрос: **какие переиспользуемые активы уже есть у
организации и какие строки каталога возможностей (FEATURES_INDEX, разделы
I–IV) их наполняют**. Каждая строка каталога либо присоединена к семейству
(поле `feature_ids` узла), либо лежит в списке неприсоединённых с причиной —
тихих потерь нет.

## Представление

Карточки семейств активов несут права (`open` / `rights-gated` /
`quarantine`), запрет пересоздания и чипы присоединённых строк. Ниже —
полный список неприсоединённых строк с причинами.
